# Esports360 Wireframes 2026

This SVG is designed to be imported into Figma as a starting point for structure, navigation, and reusable components.

## How to use
1. Open GitHub → `Design/esports360_wireframes_2026.svg`
2. Click **Raw** button to get the raw URL
3. Download the file
4. Drag & drop it into Figma canvas
5. Split groups into pages: Foundations, Components, Screens, Flows

## Contents
- App navigation flow
- Home, Tournaments, Tournament Detail, Bracket wireframes
- Discover, Team Detail, Match Detail, Settings wireframes
- Core components (Button, Badge, Card, Row, TabBar, Empty State, Skeleton)
- Figma pages workflow guide
