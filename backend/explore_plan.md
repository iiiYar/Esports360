# 🏛️ المخطط المعماري وخطة العمل لترقية صفحة "استكشف" (Discover / Explore View Plan)

تهدف هذه الخطة إلى ترقية صفحة **"استكشف" (Discover)** في تطبيق **Esports360** من مجرد شبكة عرض بسيطة للألعاب إلى **مركز اكتشاف متكامل وذكي (Ultimate Discovery Hub)** يتيح للمستخدمين البحث الشامل، متابعة البطولات الكبرى والفرق الرائدة، والدخول في أجنحة ألعاب مخصصة (Dedicated Game Hubs) بتجربة مستخدم فاخرة ومثيرة.

---

## 🎨 أولاً: تجربة وأقسام الواجهة الجديدة (Discover UI Sections)

سنقوم بإعادة صياغة الواجهة بالاعتماد على المظهر الداكن الفاخر (Amoled Dark Mode) والتحريكات الناعمة والتدرجات اللونية المطابقة لهوية كل لعبة:

### 1. 🔍 شريط البحث الشامل المتقدم (Unified Global Search)
*   **الوصف:** شريط بحث عائم في أعلى الصفحة مع لمسة زجاجية (Glassmorphic Backdrop).
*   **التفاعل:** بمجرد نقر المستخدم عليه، يُفتح تراكب بحث ذكي (Search Overlay).
*   **النتائج:** يتم فرز النتائج لحظياً تحت ثلاثة أقسام رئيسية:
    *   **الفرق (Teams):** شعارات الفرق، الاسم، واللعبة (مثل: *Natus Vincere - CS2*).
    *   **البطولات (Tournaments):** اسم البطولة وتاريخها وحالتها (مثل: *PGL Major Copenhagen*).
    *   **اللاعبين (Players):** صورة اللاعب، اسمه، والفرق الذي يلعب له.

### 2. 🏆 كاروسيل البطولات النشطة والمميزة (Featured Tournaments Carousel)
*   **الوصف:** شريط تمرير أفقي (Horizontal Carousel) يعرض كروت بطولات كبرى نشطة أو قادمة بتصميم غامر.
*   **العناصر داخل الكارت:** اسم البطولة، شعارها الرسمي، أيقونة اللعبة، تاريخ البدء والانتهاء، وشارة مضيئة ملونة تدل على حالة البطولة (🔴 مباشر الآن / 📅 قريباً).

### 3. 🎮 جناح الألعاب التفاعلي والدخول للـ Game Hubs
*   **الوصف:** الاحتفاظ بالشبكة الحالية الأنيقة لعرض كروت الألعاب (`GameCatalogCard`) ولكن مع تحويلها إلى **بوابة عبور (Entry Point)**:
    *   عند قيام المستخدم بالنقر على كارت لعبة معينة (مثل CS2)، يفتح التطبيق شاشة مخصصة بالكامل تسمى **جناح اللعبة (Game Hub View)**.
    *   **محتويات الـ Game Hub:**
        *   أحدث المباريات الجارية والقادمة لهذه اللعبة فقط.
        *   قائمة بجميع بطولاتها النشطة والمجدولة.
        *   أقوى الفرق وأكثرها متابعة في هذه اللعبة مع إمكانية متابعتها مباشرة.

### 4. 👥 الفرق الرائدة والأكثر شعبية (Trending Teams to Follow)
*   **الوصف:** قائمة أفقية ناعمة تضم الفرق الأكثر شهرة ومتابعة على المنصة.
*   **العناصر:** كارت الفريق الدائري يحتوي على الشعار، اسم الفريق، شارة اللعبة، وزر **"متابعة فوري" (Quick Follow)** الحركي الذي يهتز لمسياً (Haptic Feedback) عند النقر لإضافة الفريق لقائمة المفضلة مباشرة.

## 🧠 ثانياً: معمارية الباك اند والـ APIs المطلوبة

لدعم هذه التجربة السريعة، سنقوم ببناء 3 مسارات API ذكية ومحسنة في الباك اند:

### 1. مسار البحث الشامل (`GET /v1/discover/search?q=...`)
*   **الوظيفة:** يبحث في جداول `teams` و `tournaments` و `players` باستخدام محرك بحث نصي مرن في Postgres (ILIKE أو pg_trgm لضمان السرعة الفائقة).
*   **الاستجابة:**
    ```json
    {
      "teams": [{"id": "...", "name": "NaVi", "logo_url": "...", "game_code": "cs2"}],
      "tournaments": [{"id": "...", "name": "BLAST Premier", "logo_url": "...", "game_code": "cs2", "status": "live"}],
      "players": [{"id": "...", "name": "s1mple", "image_url": "...", "team_name": "NaVi"}]
    }
    ```

### 2. مسار العناصر المميزة والنشطة (`GET /v1/discover/trending`)
*   **الوظيفة:** يجمع البطولات النشطة الكبرى والفرق الأكثر متابعة في طلب واحد سريع جداً لتقليل استهلاك الشبكة (Single Network Roundtrip).

### 3. مسار جناح اللعبة المخصص (`GET /v1/games/{code}/hub`)
*   **الوظيفة:** يرجع كل ما يخص لعبة معينة:
    *   المباريات الحية واليومية المصفاة للعبة.
    *   ترتيب أشهر 5 فرق ومتابعاتهم.
    *   البطولات الفعالة حالياً للعبة.
